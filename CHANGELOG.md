# Changelog

All notable changes to Velora Civic AI are documented here.

## [2.0.0] — Final Submission

### Foundation (Phases 1–6)

- **Phase 1** — Next.js 14 + TypeScript + Tailwind + shadcn/ui foundation,
  interactive India map, seeded demo data, Firebase + Gemini config.
- **Phase 2** — Citizen reporting (photo, voice, geolocation) with Firebase
  Storage + Firestore.
- **Phase 3** — Deterministic aggregation engine: reports → civic cases.
- **Phase 4** — Civic Intelligence: visible AI reasoning (classification,
  transcript, summaries).
- **Phase 5** — Operations Center: status workflow, admin dashboard, analytics.
- **Phase 6** — Production polish: loading/error states, accessibility, docs.

### Upgrades (U1–U5.1)

- **U1 — Integrity & Credibility:** anonymous reporter identity, scoped
  "My Reports", aggregation false-merge guard, voice reliability.
- **U2 — Context Intelligence:** Geocoding + Places → explainable,
  context-aware severity.
- **U3 — Agentic Operations:** explainable priority, recommendations, operations
  brief, and timeline.
- **U4 — Civic Intelligence & Trust:** Civic Health Index, explainable insights,
  trust indicators, decision-transparency panel, community impact.
- **U5 — Premium Experience:** active navigation, hero, animated KPIs,
  category distribution, map polish.
- **U5.1 — Premium Design System:** refined tokens, ambient identity, elevated
  primitives, motion system, light/dark theme toggle.

### Final Release (U6)

- Full audit, dead-code removal, security review, submission-grade docs, and
  GitHub governance files.
